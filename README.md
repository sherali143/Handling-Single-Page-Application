

# SPA Page Handling in Browser Extensions

This repository provides a guide for handling page changes in Single Page Applications (SPAs) like **GitHub**, **Twitter**, and **YouTube** for browser extensions.

## Overview
SPAs dynamically update content without full page reloads, which can be challenging for browser extensions. This guide presents the best practice method for detecting page changes and executing scripts only when the new content is ready.

For detailed implementation, refer to the [wiki](https://github.com/sherali143/Handling-Single-Page-Application/wiki/Handling-SPA-Page-Changes-in-Browser-Extensions).
